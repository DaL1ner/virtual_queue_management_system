## 1. Роли и участники

| Термин | Определение |
|---|---|
| **Администратор** | Сотрудник системы, который управляет жизненным циклом очереди, настраивает конфигурации и типы обслуживания, назначает роли сотрудникам и просматривает историю событий. |
| **Исполнитель услуги** | Сотрудник, который принимает вызванного клиента, подтверждает готовность к обслуживанию, оказывает услугу и отслеживает состояние собственного обслуживания. |
| **Клиент очереди** | Пользователь, уже имеющий активный талон и клиентскую сессию. Может отслеживать состояние талона, выходить из очереди и в предусмотренном сценарии перемещаться к концу очереди на N шагов. |
| **Наблюдатель очереди** | Участник системы с доступом к общему мониторингу очереди без управления талонами и без оказания услуги. |
| **Неавторизованный клиент** | Пользователь, который ещё не вошёл в активную клиентскую сессию, но может начать постановку в очередь. |
| **Оператор** | Сотрудник, который вручную управляет потоком очереди: вызывает клиента, перемещает клиента в очереди, удаляет клиента без оказания услуги и выполняет административный мониторинг. |
| **Система** | Системный участник, инициирующий автоматические действия, например автоматический вызов первого клиента в очереди и отправку клиентских уведомлений. |

## 2. Бизнес-процессы и сценарии

| Термин | Определение |
|---|---|
| **Административный мониторинг очереди** | Сценарий расширенного наблюдения за очередью для оператора и администратора: просмотр текущей очереди, вызовов, состояний исполнителей и агрегированных показателей обслуживания. |
| **Авторизация в системе** | Сценарий входа сотрудника по логину и паролю с проверкой активной сессии и созданием новой сессии сотрудника. |
| **Автоматический вызов первого клиента в очереди** | Сценарий, при котором система автоматически связывает первого клиента в очереди со свободным исполнителем. |
| **Автоматическое управление потоком очереди** | Контур управления очередью, в котором назначение клиента исполнителю может инициироваться системой автоматически. |
| **Выход из очереди** | Сценарий добровольного отказа клиента от ожидания с переводом талона в статус «отменён» и завершением клиентской сессии. |
| **Вызов клиента в очереди** | Сценарий назначения клиента исполнителю с переводом талона в статус «вызван». |
| **Мониторинг обслуживания** | Сценарий исполнителя по просмотру сведений о вызванном клиенте, числе клиентов в очереди и собственных показателях обслуживания. |
| **Мониторинг состояния собственного талона** | Сценарий клиента по просмотру номера талона, позиции в очереди, числа людей впереди, времени ожидания и назначенного исполнителя. |
| **Настройка очереди** | Административный сценарий работы с конфигурацией очереди и типами обслуживания. |
| **Общий мониторинг очереди** | Сценарий наблюдения за очередью без управления талонами: просмотр вызовов, числа клиентов и общих показателей обслуживания. |
| **Оказание услуги** | Сценарий работы исполнителя с вызванным клиентом: подтверждение начала обслуживания, оказание услуги, фиксация результата или отсутствия клиента. |
| **Перемещение клиента в очереди** | Сценарий изменения позиции клиента в очереди оператором или администратором. |
| **Перемещение к концу очереди на N шагов** | Сценарий клиента, при котором его талон переносится назад на указанное число шагов с пересчётом позиции и приоритета. |
| **Постановка в очередь** | Начальный сценарий клиента: ввод имени и фамилии, выбор типа обслуживания, создание клиентской сессии, инициализация талона и первичный расчёт порядка в очереди. |
| **Просмотр истории событий** | Административный сценарий получения журнала событий системы. |
| **Ручное управление потоком очереди** | Контур управления очередью, в котором вызов, перемещение и удаление клиента инициируются сотрудником. |
| **Смена готовности к оказанию услуги** | Сценарий исполнителя по подтверждению или отмене своей готовности принять следующего клиента. |
| **Удаление клиента из очереди без оказания услуги** | Сценарий принудительного исключения клиента из очереди без перевода в статус «обслужен». |
| **Уведомление клиента о действиях с его талоном** | Сквозной сценарий, в котором система получает сведения об изменении состояния талона, определяет объект изменений и отправляет уведомление клиенту. |
| **Управление жизненным циклом очереди** | Административный сценарий запуска, приостановки, возобновления и завершения очереди. |
| **Управление операторами и исполнителями** | Административный сценарий создания и настройки учётных записей сотрудников, а также назначения ролей. |

| **Сессии клиентов** | Хранилище клиентских сессий. |
| **Сессии очереди** | Хранилище сессий очередей. |
| **Сессии сотрудников** | Хранилище сессий сотрудников. |
| **Сессия клиента** | Запись о текущем взаимодействии клиента с системой в рамках одного талона. |
| **Сессия очереди** | Запись о текущем жизненном цикле конкретной очереди. |

| **Событие вызова** | Событие назначения клиента исполнителю, используемое в механизме уведомления исполнителя. |

| **Талон** | Базовая сущность очереди, представляющая клиента в процессе ожидания, вызова и обслуживания. |
| **Талоны** | Коллекция талонов, используемая для расчёта очереди, мониторинга и управления потоком. |
| **Тип обслуживания** | Выбираемая клиентом категория обслуживания, от которой зависит обработка талона. |

| **Учётные данные сотрудников** | Хранилище логинов и других данных сотрудников, используемых при авторизации и администрировании. |
| **Уведомление** | Сообщение, направляемое клиенту или исполнителю при значимом событии. |
| **Число шагов перемещения** | Вводимое значение, определяющее, на сколько позиций клиент смещается к концу очереди. |

## 4. Статусы, состояния и режимы

### 4.1. Статусы талона

| Термин | Определение |
|---|---|
| **Вызван** | Статус талона, в котором клиент уже назначен исполнителю и ожидает начала обслуживания. |
| **Обслужен** | Статус талона после успешного завершения оказания услуги. |
| **Обслуживается** | Статус талона в момент активного оказания услуги. |
| **Ожидает** | Начальный активный статус талона после постановки клиента в очередь. |
| **Отменён** | Статус талона, в который клиент переводится при выходе из очереди или удалении без оказания услуги. |
| **Пропущен** | Статус талона, фиксирующий, что вызванный клиент не приступил к обслуживанию. |

### 4.2. Статусы сессии очереди

| Термин | Определение |
|---|---|
| **Активна** | Состояние сессии очереди, в котором очередь работает в обычном режиме. |
| **Завершена** | Состояние сессии очереди после её окончательного закрытия. |
| **На паузе** | Состояние сессии очереди, при котором её работа временно приостановлена. |

### 4.3. Состояния исполнителя

| Термин | Определение |
|---|---|
| **Готов** | Состояние исполнителя, в котором он доступен для назначения следующего клиента. |
| **Не готов** | Состояние исполнителя, в котором он временно недоступен для нового назначения. |

### 4.4. Режимы управления

| Термин | Определение |
|---|---|
| **Автоматическое управление потоком очереди** | Режим, в котором система сама инициирует вызов первого клиента при наличии подходящих условий. |
| **Ручное управление потоком очереди** | Режим, в котором действия с потоком очереди выполняет оператор или администратор. |

## 5. Мониторинг и показатели

| Термин | Определение |
|---|---|
| **Информация о вызванном клиенте** | Данные о клиенте, который уже назначен исполнителю и ожидает или начал обслуживание. |
| **Информация о назначенном исполнителе** | Сведения о сотруднике, закреплённом за конкретным талоном. |
| **Информация о номере талона** | Отображаемый клиенту идентификатор его талона. |
| **Общее среднее время обслуживания** | Средний показатель времени обслуживания по очереди в целом. |
| **Общее число обслуженных клиентов** | Совокупное количество клиентов, успешно завершивших обслуживание. |
| **Примерное время ожидания клиента** | Расчётная оценка времени до начала обслуживания конкретного клиента. |
| **Список текущей очереди** | Текущее упорядоченное представление активных талонов очереди. |
| **Список текущих вызовов** | Список клиентов, которые уже вызваны и связаны с исполнителями. |
| **Среднее время обслуживания исполнителя** | Среднее время, за которое конкретный исполнитель обслуживает клиентов. |
| **Среднее время ожидания** | Усреднённая оценка ожидания, отображаемая клиенту при мониторинге собственного талона. |
| **Текущая позиция в очереди** | Текущее место клиента относительно остальных талонов. |
| **Число клиентов в очереди** | Количество талонов, находящихся в активной очереди. |
| **Число людей впереди очереди** | Количество клиентов, стоящих перед конкретным талоном. |
| **Число обслуженных клиентов исполнителя** | Показатель, отражающий, сколько клиентов обслужил конкретный исполнитель. |

| **Сервис доступа к данным** | Технологический сервис обращения прикладного слоя к серверу базы данных. |

| **Сервис настройки очереди** | Прикладной сервис работы с конфигурациями очереди и типами обслуживания. |
| **Сервис оказания услуги** | Прикладной сервис, поддерживающий сценарии начала, ведения и завершения обслуживания. |
| **Сервис расчёта метрик времени обслуживания** | Прикладной сервис предоставления расчётных показателей мониторинга. |
| **Сервис расчёта очереди** | Прикладной сервис вычисления позиций, очередности и связанных показателей очереди. |
| **Сервис уведомления клиента** | Прикладной сервис формирования и отправки уведомлений клиенту. |
| **Сервис уведомления исполнителя** | Прикладной сервис информирования исполнителя о назначении клиента. |
| **Сервис управления вызовами** | Прикладной сервис связывания клиента с исполнителем, управления вызовами и состояниями исполнителей. |
| **Сервис управления операторами и исполнителями** | Прикладной сервис создания учётных записей сотрудников и назначения им ролей. |
| **Сервис управления сессиями** | Прикладной сервис работы с клиентскими и сотрудническими сессиями. |

| **Сервис хранения данных** | Технологический сервис физического хранения прикладных данных системы. |

| **Управление талонами** | Внутренняя подсистема, через которую выполняются переводы статусов талонов, фиксация времени обслуживания и назначение приоритета. |

## 7. Технологическая архитектура и инфраструктура

| Термин | Определение |

## 9. Ключевые проектные и технические понятия

| Термин | Определение |
|---|---|
| **Вычисление объекта изменений** | Определение того, какое именно изменение талона произошло и что должно быть отражено в уведомлении. |
| **Назначение порядка сортировки в очереди** | Операция записи нового сортировочного порядка талона внутри очереди. |
| **Назначение приоритета** | Операция задания или изменения приоритета талона. |
| **Отвязывание клиента от исполнителя** | Разрыв связи между исполнителем и ранее назначенным ему клиентом после завершения или пропуска обслуживания. |
| **Отправка уведомления клиенту** | Финальная операция доставки сформированного уведомления клиенту. |
| **Отправка уведомления исполнителю** | Операция доставки исполнителю сведений о назначении клиента. |
| **Первичный расчёт порядка сортировки в очереди** | Начальное вычисление места нового талона в очереди. |
| **Перевод исполнителя в статус «готов»** | Операция, делающая исполнителя доступным для нового назначения. |
| **Перевод исполнителя в статус «не готов»** | Операция, временно исключающая исполнителя из списка доступных для назначения. |
| **Перерасчёт порядка сортировки в очереди** | Операция обновления порядка талонов после перемещения, удаления или изменения приоритета. |
| **Перерасчёт уровня приоритета** | Операция повторного определения приоритета талона после изменения его позиции или условий обработки. |
| **Проверка корректности логина** | Проверка введённого логина на соответствие данным учётной записи. |
| **Проверка корректности пароля** | Проверка пароля для завершения авторизации сотрудника. |
| **Проверка наличия активной сессии** | Операция определения, существует ли уже активная клиентская или сотрудническая сессия. |
| **Проверка наличия клиентов** | Операция, подтверждающая, что в очереди есть клиенты для дальнейшего обслуживания или управления. |
| **Проверка наличия свободных исполнителей** | Операция определения, есть ли исполнители в состоянии «готов». |
| **Проверка на начало обслуживания** | Контроль, не начал ли клиент уже обслуживание в момент выхода из очереди или другой операции с талоном. |
| **Проверка новой позиции на корректность** | Проверка допустимости новой позиции клиента перед изменением очереди. |
| **Просмотр информации о клиенте** | Техническая операция получения данных о клиенте по его талону. |
| **Расчёт текущей позиции в очереди** | Вычисление фактического места клиента среди активных талонов. |
| **Связывание исполнителя с клиентом** | Операция назначения конкретного клиента конкретному исполнителю. |
| **Связывание исполнителя с первым клиентом** | Частный случай автоматического назначения, при котором выбирается первый клиент из очереди. |
| **Фиксация времени начала/конца обслуживания** | Запись временных отметок начала и завершения обслуживания по талону. |
| **Фиксация отсутствия клиента** | Операция подтверждения, что вызванный клиент не появился для обслуживания. |
| **Фиксация оказания услуги** | Операция завершения обслуживания с подтверждением факта оказания услуги. |
| **Формирование списка очереди** | Построение актуального представления очереди для управления и мониторинга. |
| **Формирование текста уведомления** | Подготовка содержимого сообщения перед отправкой клиенту. |

## 11. Архитектурные стили

| Термин | Определение |
|---|---|
| **Клиент-серверное взаимодействие** | Архитектурная организация, в которой пользователь работает через браузер, а обработка запросов и хранение данных выполняются серверными компонентами. |
