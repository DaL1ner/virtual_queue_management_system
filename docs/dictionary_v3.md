## 1. Роли и участники

| Термин | Определение |
|---|---|
| **Администратор** | Роль сотрудника, отвечающая за управление жизненным циклом очереди, настройку очереди, управление операторами и исполнителями, а также за просмотр истории событий и административный мониторинг. |
| **Исполнитель услуги** | Роль сотрудника, который подтверждает готовность к оказанию услуги, принимает вызванного клиента, оказывает услугу и фиксирует результат обслуживания. |
| **Клиент очереди** | Клиент, уже включённый в очередь. Может отслеживать собственный талон, получать уведомления, выходить из очереди и в предусмотренном сценарии перемещаться к концу очереди на N шагов. |
| **Наблюдатель очереди** | Участник системы, имеющий доступ к общему мониторингу очереди без выполнения действий по вызову, перемещению или удалению клиента. |
| **Неавторизованный клиент** | Внешний клиент до создания клиентской сессии. Использует сценарий постановки в очередь. |
| **Оператор** | Роль сотрудника, работающая с текущим потоком очереди: вызывает клиента, перемещает клиента в очереди, удаляет клиента без оказания услуги и использует административный мониторинг очереди. |
| **Система** | Системный участник, инициирующий автоматический вызов первого клиента в очереди и отправку уведомлений клиенту. |

## 2. Бизнес-процессы и сценарии

| Термин | Определение |
|---|---|
| **Административный мониторинг очереди** | Сценарий расширенного наблюдения за очередью для оператора и администратора с доступом к текущим вызовам, текущей очереди, числу клиентов, числу обслуженных клиентов и состояниям исполнителей. |
| **Авторизация в системе** | Сценарий входа исполнителя, оператора или администратора по логину и паролю с проверкой активной сессии и инициализацией новой сессии сотрудника. |
| **Автоматический вызов первого клиента в очереди** | Сценарий, в котором система при наличии готового исполнителя автоматически связывает его с первым клиентом в очереди. |
| **Автоматическое управление потоком очереди** | Контур управления, в котором назначение клиента исполнителю инициируется системой без ручного выбора оператора. |
| **Вызов клиента в очереди** | Сценарий назначения клиента исполнителю и перевода талона в состояние вызова. |
| **Выход из очереди** | Сценарий добровольного выхода клиента из очереди с переводом талона в статус отмены и завершением клиентской сессии. |
| **Мониторинг обслуживания** | Сценарий наблюдения исполнителем за ходом обслуживания, вызванным клиентом и связанными показателями. |
| **Мониторинг состояния собственного талона** | Сценарий, в котором клиент просматривает номер талона, текущую позицию, число людей впереди, среднее время ожидания и назначенного исполнителя. |
| **Настройка очереди** | Административный сценарий создания, удаления и изменения конфигурации очереди и типов обслуживания. |
| **Общий мониторинг очереди** | Сценарий наблюдения за очередью без управляющих действий: просмотр текущих вызовов, числа клиентов, общего среднего времени обслуживания и других общих показателей. |
| **Оказание услуги** | Сценарий работы исполнителя с вызванным клиентом: подтверждение начала обслуживания, процесс оказания услуги, фиксация оказания услуги или фиксация отсутствия клиента. |
| **Перемещение клиента в очереди** | Сценарий изменения позиции клиента внутри очереди оператором или администратором. |
| **Перемещение к концу очереди на N шагов** | Сценарий клиента очереди, при котором клиент вводит число шагов N, а система сдвигает его талон назад в очереди на указанное количество позиций. |
| **Постановка в очередь** | Начальный сценарий клиента: ввод имени и фамилии, выбор типа обслуживания, создание клиентской сессии, инициализация талона и первичный расчёт порядка сортировки в очереди. |
| **Просмотр истории событий** | Административный сценарий просмотра журнала событий системы. |
| **Ручное управление потоком очереди** | Контур управления, в котором вызов, перемещение и удаление клиента инициируются оператором или администратором. |
| **Смена готовности к оказанию услуги** | Сценарий, в котором исполнитель подтверждает готовность к оказанию услуги или отменяет её. |
| **Удаление клиента из очереди без оказания услуги** | Сценарий исключения клиента из очереди оператором или администратором без перевода в статус обслуживания. |
| **Уведомление клиента о действиях с его талоном** | Сквозной сценарий, в котором система получает информацию об изменениях талона, определяет объект изменений, формирует текст уведомления и отправляет его клиенту. |
| **Управление жизненным циклом очереди** | Административный сценарий инициализации очереди, перевода очереди в состояние паузы или активности и завершения очереди. |
| **Управление операторами и исполнителями** | Административный сценарий создания и удаления учётных записей сотрудников, а также назначения ролей сотрудникам. |

## 3. Сущности, данные и связи

| Термин | Определение |
|---|---|
| **Данные конфигурации** | Данные, вводимые и изменяемые в сценариях настройки очереди. На их основе формируется конфигурация очереди. |
| **Данные типа обслуживания** | Данные, используемые для создания, удаления и настройки типов обслуживания. |
| **Данные учётных записей** | Вводимые данные для создания, удаления и настройки учётных записей сотрудников. |
| **Имя и фамилия** | Персональные данные, которые клиент вводит при постановке в очередь. |
| **Конфигурация очереди** | Набор параметров очереди, задающий правила её работы и используемый в жизненном цикле очереди и её настройке. |
| **Логин** | Идентификатор сотрудника, вводимый при авторизации в системе. |
| **Новая позиция** | Целевое место клиента в очереди при сценарии перемещения клиента в очереди. |
| **Пароль** | Секретные учётные данные сотрудника, вводимые при авторизации. |
| **Позиция** | Значение места клиента в очереди, используемое во внутренних сценариях выбора новой позиции. |
| **Порядок сортировки в очереди** | Правило расположения талонов в очереди, которое назначается при создании талона и пересчитывается при перемещениях и изменении приоритета. |
| **Приоритет** | Характеристика талона, влияющая на порядок сортировки клиента в очереди. |
| **Роли** | Набор ролей сотрудников системы, используемый при назначении прав оператору, исполнителю и администратору. |
| **Связь исполнителя с клиентом** | Актуальная связь между исполнителем и вызванным клиентом, создаваемая при вызове и снимаемая после завершения обслуживания или отвязывания клиента. |
| **Связь сотрудников с ролями** | Данные о назначении ролей сотрудникам. |
| **Сессия клиента** | Сущность, отражающая активное взаимодействие клиента с системой от постановки в очередь до выхода из очереди или завершения обслуживания. |
| **Сессия очереди** | Сущность, отражающая текущий жизненный цикл очереди: инициализацию, активность, паузу и завершение. |
| **Сессия сотрудника** | Активная сессия исполнителя, оператора или администратора после успешной авторизации. |
| **Состояния исполнителей** | Данные о текущем состоянии исполнителей, используемые в вызовах, мониторинге и оказании услуги. |
| **Талон** | Основная сущность системы, представляющая клиента в очереди и фиксирующая его состояние, позицию, приоритет и связь с обслуживанием. |
| **Тип обслуживания** | Категория обслуживания, выбираемая клиентом при постановке в очередь и используемая при назначении приоритета талону. |
| **Учётные данные сотрудников** | Хранимые данные сотрудников, используемые при авторизации и административном управлении пользователями системы. |
| **Уведомление** | Сообщение, формируемое системой для клиента или исполнителя при назначении клиента или изменении состояния талона. |
| **Число шагов перемещения** | Значение, задающее, на сколько шагов клиент перемещается к концу очереди в соответствующем сценарии. |

## 4. Статусы и состояния

### 4.1. Статусы талона

| Термин | Определение |
|---|---|
| **Вызван** | Статус талона, при котором клиент уже назначен исполнителю и ожидает начала обслуживания. |
| **Обслужен** | Статус талона после успешного завершения оказания услуги. |
| **Обслуживается** | Статус талона в момент активного оказания услуги клиенту. |
| **Ожидает** | Начальный активный статус нового талона после постановки в очередь. |
| **Отменён** | Статус талона клиента, покинувшего очередь или удалённого без обслуживания. |
| **Пропущен** | Статус талона клиента, который был вызван, но не приступил к обслуживанию. |

### 4.2. Состояния исполнителя

| Термин | Определение |
|---|---|
| **Готов** | Состояние исполнителя, при котором он может принять следующего клиента. |
| **Не готов** | Состояние исполнителя, при котором он временно не может принять нового клиента. |

### 4.3. Состояния сессии очереди

| Термин | Определение |
|---|---|
| **Активна** | Состояние очереди, в котором она функционирует и обслуживает клиентов. |
| **Завершена** | Состояние очереди после окончания её жизненного цикла. |
| **Пауза** | Состояние очереди, в котором её работа временно приостановлена. |

## 5. Мониторинг и показатели

| Термин | Определение |
|---|---|
| **Информация о вызванном клиенте** | Данные о клиенте, уже назначенном исполнителю для обслуживания. |
| **Информация о клиенте** | Данные о клиенте, используемые в мониторинге талона и в процессе обслуживания. |
| **Назначенный исполнитель** | Исполнитель, закреплённый за конкретным клиентом или талоном. |
| **Номер талона** | Видимый идентификатор талона клиента, отображаемый в сценариях мониторинга. |
| **Общее среднее время обслуживания** | Сводный показатель среднего времени обслуживания по очереди в целом. |
| **Общее число обслуженных клиентов** | Суммарный показатель клиентов, успешно обслуженных в очереди. |
| **Примерное время ожидания клиента** | Расчётная оценка времени, которое клиенту осталось ждать до начала обслуживания. |
| **Список текущей очереди** | Актуальный перечень талонов, находящихся в очереди в данный момент. |
| **Список текущих вызовов** | Актуальный перечень клиентов, уже вызванных к исполнителям. |
| **Среднее время обслуживания исполнителя** | Показатель среднего времени обслуживания по конкретному исполнителю. |
| **Среднее время ожидания** | Показатель ожидаемого времени до обслуживания, доступный клиенту в мониторинге собственного талона. |
| **Текущая позиция в очереди** | Текущее место клиента в очереди. |
| **Число клиентов в очереди** | Количество клиентов, находящихся в активной очереди. |
| **Число людей впереди очереди** | Количество клиентов, стоящих перед конкретным талоном. |
| **Число обслуженных клиентов исполнителя** | Количество клиентов, которых обслужил конкретный исполнитель. |

## 6. Сервисы и внутренние подсистемы

### 6.1. Сервисы

| Термин | Определение |
|---|---|
| **Сервис авторизации** | Прикладной сервис, обеспечивающий проверку логина и пароля сотрудника при входе в систему. |
| **Сервис ввода информации** | Прикладной сервис, через который вводятся данные клиента, данные конфигурации и параметры отдельных операций с очередью. |
| **Сервис доступа к данным** | Технологический сервис, обеспечивающий доступ прикладного уровня к данным, размещённым на сервере БД. |
| **Сервис доступа к веб-приложению** | Технологический сервис, обеспечивающий пользователю доступ к веб-приложению с клиентского устройства. |
| **Сервис настройки очереди** | Прикладной сервис, обеспечивающий создание, удаление и изменение конфигурации очереди и типов обслуживания. |
| **Сервис оказания услуги** | Прикладной сервис, поддерживающий сценарии начала, хода и завершения обслуживания клиента. |
| **Сервис просмотра истории событий** | Прикладной сервис, через который администратор просматривает историю событий системы. |
| **Сервис расчёта метрик времени обслуживания** | Прикладной сервис вычисления примерного времени ожидания и средних показателей обслуживания. |
| **Сервис расчёта очереди** | Прикладной сервис, обеспечивающий расчёт текущей позиции, формирование списка очереди и пересчёт сортировки талонов. |
| **Сервис управления вызовами** | Прикладной сервис, поддерживающий вызов клиента, связывание клиента с исполнителем, отвязывание клиента и просмотр данных о вызовах. |
| **Сервис управления операторами и исполнителями** | Прикладной сервис административного управления учётными записями сотрудников и назначением ролей. |
| **Сервис управления сессиями** | Прикладной сервис создания, проверки и завершения клиентских и сотруднических сессий. |
| **Сервис управления сессиями очередей** | Прикладной сервис, управляющий инициализацией, паузой, активацией и завершением очереди. |
| **Сервис управления талонами** | Прикладной сервис, управляющий состояниями талонов, временем обслуживания, приоритетом и порядком сортировки. |
| **Сервис уведомления клиента** | Прикладной сервис, формирующий и отправляющий клиенту уведомления об изменениях талона. |
| **Сервис уведомления исполнителя** | Прикладной сервис, отправляющий исполнителю уведомление о назначении клиента. |
| **Сервис хранения данных** | Технологический сервис, обеспечивающий физическое хранение данных на сервере БД. |

### 6.2. Внутренние подсистемы

| Термин | Определение |
|---|---|
| **Автоматический вызов** | Внутренняя подсистема, реализующая автоматическое связывание свободного исполнителя с первым клиентом в очереди. |
| **Авторизация в системе** | Внутренняя подсистема, выполняющая проверку логина и пароля и создающая сессию сотрудника. |
| **Ввод информации на стороне пользователя** | Внутренняя подсистема, через которую пользователь или администратор вводит данные для постановки в очередь, авторизации, настройки или операций с очередью. |
| **Настройка очереди** | Внутренняя подсистема изменения конфигурации очереди и типов обслуживания. |
| **Просмотр истории событий** | Внутренняя подсистема просмотра журнала событий системы. |
| **Расчёт метрик времени обслуживания** | Внутренняя подсистема вычисления времени ожидания и средних показателей обслуживания. |
| **Расчёт очереди** | Внутренняя подсистема расчёта текущей позиции клиента, пересчёта приоритета и порядка сортировки, а также формирования списка очереди. |
| **Ручной вызов** | Внутренняя подсистема ручного назначения клиента свободному исполнителю. |
| **Уведомление клиента о действиях с его талоном** | Внутренняя подсистема, формирующая и отправляющая клиенту уведомления при изменении состояния талона. |
| **Уведомление о назначении клиента** | Внутренняя подсистема, отправляющая исполнителю уведомление о назначении клиента. |

## 7. Технологическая архитектура и инфраструктура

| Термин | Определение |
|---|---|
| **Docker** | Средство контейнеризации, используемое на сервере приложения и сервере БД. |
| **LAN** | Локальная сеть, связывающая технологические узлы внутри инфраструктуры проекта. |
| **PostgreSQL** | Система управления базами данных, размещённая на сервере БД. |
| **Ubuntu Server** | Серверная операционная система, указанная для сервера приложения и сервера БД. |
| **WAN** | Внешняя сеть, через которую соединяются пользовательское устройство и серверная часть. |
| **WLAN** | Беспроводной сегмент сети, через который пользовательское устройство может подключаться к системе. |
| **Веб-браузер** | Клиентское средство доступа пользователя к веб-приложению. |
| **Сервер БД** | Инфраструктурный узел, в котором размещены PostgreSQL и хранилища данных системы. |
| **Сервер приложения** | Инфраструктурный узел, на котором размещено веб-приложение и прикладные сервисы проекта. |
| **Устройство пользователя** | Техническое устройство клиента, имеющее доступ к веб-браузеру и веб-приложению. |
