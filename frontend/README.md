# Фронтенд

## Разрабатываемые MVP интерфейсы

### Интерфейс клиента (студента)

Отображает информацию о собственном талоне и доступную информацию об очереди.    
В верхней части экрана отображается примерное время ожидания в очереди.
В верхней части экрана имеется меню с опцией выхода из аккаунта (как следствие и из очереди).  
При вызове данного клиента у него появляется информация о вызове.

### Интерфейс Оператора + Исполнителя

Оптимально совмещает в себе функционал двух ролей.
Отображает актуальную очередь в виде списка. Каждый элемент списка содержит номер талона, имя и фамилию (если оно есть) и примечание (если оно есть). Приоритетные клиенты выделяются. Помимо этого у каждого элемента списка есть кнопки для управления: вызов, удаление. При зажатии элемента списка курсором, его можно перетянуть в любое место списка, и, тем самым, переместить клиента по очереди.  
Над списком очереди отображается список вызванных пользователей, элементы которого содержат номер вызванного талона, имя и фамилию клиента (если они есть), имя и фамилию исполнителя (или, в общем случае, кабинет или окно).  
В верхней части присутствует кнопка "Вызвать следующего", меняющаяся на кнопку "Завершить защиту" после вызова клиента. Нажатие на кнопку "Вызвать следующего" на стороне сервера является подтверждением готовности оператора к обслуживанию + вызов первого в очереди. Кнопка "Вызвать следующего" заблокирована, если очередь пуста.  
В верхней части экрана имеется меню с опцией выхода из аккаунта.
